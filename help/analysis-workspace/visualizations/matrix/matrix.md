# マトリックスの概要 {#matrix-overview}

Analysis Workspaceの行列ビジュアライゼーションを使用すると、2つのディメンションのディメンション項目の重なり合いや相関関係を確認できます。

1つのディメンションのDimension項目は行（Y軸に沿って）に表示され、他のディメンションのディメンション項目は列（X軸に沿って）に表示されます。 交差する各セルには、選択した指標に基づく重複データまたは相関データが表示されます。

例えば、次のマトリックスのビジュアライゼーションは、デバイス名のイベントの重複カウントを国コードで示しています。

* Dimension 1 （行ディメンション）：デバイス名

* Dimension 2 （列ディメンション）：国コード

* 指標：イベント

![ マトリックスの概要](assets/matrix-overview.png)

## 主な特長

* **2つの異なるディメンションを比較**:1つのディメンションのアイテムが別のディメンションのアイテムにどのように関連しているかを確認します。

* **ディメンションと自分自身を比較する**：同じディメンション内の項目がどのように関連付けられているかを確認します。

* **重複**: ディメンション項目の重複を表示します。

* **相関関係**: -1 （常に反対方向に移動）から+1 （常に一緒に移動）までのスケールで、ディメンション項目の傾向を詳しく確認します。

* **ヒートマップの色**：セルの色は、重なり合いが高いか低いか、または相関関係が正か負か、およびどの程度強いかを示します。 オーバーラップと相関関係には、別々のカラーパレットがあります。

## 潜在的なインサイト

* 2つの側面のパターンとギャップを見つける。 例えば、次のような質問に答えることができます。

  * 一部の地域では効果を発揮するものの、他の地域では効果を発揮しないキャンペーンはどれか？

  * 各デバイスタイプで最もパフォーマンスが高いコンテンツの種類は？

* ディメンション項目の相互の関係の傾向を調べます。 例えば、次のような質問に答えることができます。

  * 時間の経過とともに変化するマーケティングチャネル、独立して動くマーケティングチャネル、反対方向に動くマーケティングチャネルはどれですか？

  * トラフィックが増減しているページはどれか？

* ディメンションと自分自身の比較。 例えば、次のような質問に答えることができます。

  * 同じ人がよく購入する商品はどれですか？

  * 携帯電話やタブレットなど、同じ人が一緒に使用するデバイスはどれですか？

## 行列、フリーフォームテーブル、ベン、散布図のいずれかを選択します

マトリックスのビジュアライゼーションは、フリーフォームテーブル ](/help/analysis-workspace/visualizations/freeform-table/freeform-table-multidimensions.md)で複数のディメンション列を使用する[と類似しており、[ ベンのビジュアライゼーション ](/help/analysis-workspace/visualizations/venn.md)、[散布型のビジュアライゼーション ](/help/analysis-workspace/visualizations/scatterplot.md)があります。 各ビジュアライゼーションは、コンポーネント同士がどのように関連しているかを示しますが、使用するコンポーネントと結果の表示方法が異なります。

### 各ビジュアライゼーションを使用するタイミング

分析に最適なビジュアライゼーションを選択します。

* **行列：**&#x200B;特定の指標について、あるディメンションの各ディメンション項目が、他のディメンション項目の各ディメンション項目とどのように関連しているかを確認します。これには、一緒に傾向があるギャップやディメンション項目も含まれます。

* **複数のディメンション列を持つフリーフォームテーブル：** フリーフォームテーブルには、最大5つのディメンションを別々の列として追加できます。 テーブルの同じ行に表示されるDimension項目は連結されます。 テーブルに任意の数の指標を追加して、連結されたディメンション項目ごとに指標データを表示します。 連結されたディメンション項目に分類をフィルタリング、並べ替え、追加します。

* **ベン：**&#x200B;単一の指標の場合、最大3つのセグメントの重複を表示します。

* **散布図：** 2つまたは3つの指標のディメンション項目を比較して、パターンと異常値を見つけます。
