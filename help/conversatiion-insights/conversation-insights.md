# 会話のインサイト

会話インサイトを活用すれば、LLMや人間との会話を大規模に分析し、カスタマージャーニー全体のコンテクストを把握できます。 会話インサイトを通じて、実際のユーザーの成果に対するエージェントの影響を把握できます。

会話のインサイトは、発生する可能性のある問題に対処します。 例：

* Insightでは、顧客がジャーニーのコンテキストでエージェント（LLMまたは人間）とやり取りするときにどうなるかについてのインサイトを取得できません。
* 次の項目を理解する能力がありません：
  * エージェントが顧客に伝えていること。
  * 顧客が大規模にエージェントとやり取りする方法。
  * 総合的な影響についてお話しします。
* 顧客の嗜好の変化に対応しなくてはならないような、エージェント型のエクスペリエンスを構築できます。

## 仕組み

会話インサイトは、次の3つの主要機能の上に構築されています。

* データ収集：ユーザーがLLMとエージェントのタスクのパフォーマンスを把握するために必要なすべてのデータポイントを収集します。
* 信号抽出：非構造化プロンプトや応答（ターンとも呼ばれます）を、意図やセンチメントなどのレポート可能なデータポイントに変換します。 ユーザーは大規模にレポートを作成できます。
* レポート：カスタマージャーニーのコンテクストに即して会話を大規模に分析し、担当者の効果とROIを判断します。
