# データフィードでのセグメント化

{{release-limited-testing}}

Customer Journey Analyticsのデータフィードでセグメンテーションをサポートし、各フィード配信に含まれる行をフィルタリングできます。 セグメントは、データビューレベル、フィードレベル、またはその両方で適用できます。

## セグメントが適用される場所

データフィードには、次の2つの場所でセグメントを適用できます。

- **データビュー**：そのデータビューを使用するすべてのフィードに適用される、データビューで設定されたセグメント。
- **データフィード**：任意のデータビューセグメントに加えて、個々のフィードに直接適用されたセグメント。

両方が設定されている場合、Customer Journey Analyticsはそれらを組み合わせます。両方のセグメントを満たす行のみがフィード出力に含まれます。

## 日付範囲セグメント

日付範囲を参照するセグメントは、データフィードでサポートされています。 ただし、このビヘイビアーはAnalysis Workspaceとは重要な点で異なります。**セグメント内の日付範囲条件は、フィードのレポート日付範囲を上書きしません。**

Analysis Workspaceでは、日付範囲セグメントを適用すると、アクティブなレポートウィンドウがセグメントの日付範囲に合わせて変更されます。 データフィードでは、レポートウィンドウは常にフィードのスケジュールされた配信（時間単位または日単位）によって定義されます。 日付範囲の条件を持つセグメントは、そのウィンドウ内の行をフィルタリングします。ウィンドウ自体をシフトしたり展開したりしません。

このデザインは意図的です。 日付範囲のセグメントをレポートウィンドウを上書きできるようにすると、1時間あたりのフィードで、予想よりもはるかに大きなデータウィンドウが提供される可能性があり、データの重複や出力ボリュームが過剰になる可能性があります。

### 例

**例1 – 特定の日付からのイベントを含むセグメント**

7月1日のイベントのみを返すセグメントを適用し、7月22日のフィードを実行するとします。

- フィード配信ウィンドウは7月22日のままです。
- 7月22日のウィンドウ内には7月1日の条件に一致するイベントがないので、セグメントはすべての行をフィルタリングします。 フィードは実行されますが、行は配信されません。
- 7月1日にバックフィルを実行すると、セグメントは期待どおりに動作します。7月1日の条件に一致するイベントのみが含まれます。

**例2 – 特定の日付からイベントを除外するセグメント**

7月1日の注文を含むすべてのイベントを除外するセグメントを適用し、7月22日のフィードを実行するとします。

- セグメントは7月22日のデータに適用されます。 7月22日のウィンドウには7月1日のイベントがないため、何も除外されず、すべての行が配信されます。
- 7月1日にバックフィルを実行する場合、セグメントは予想どおりに関連する行を除外します。

## 複数の条件を持つセグメント

日付範囲の条件と他の基準を組み合わせたセグメントの場合、Customer Journey Analyticsは、日付範囲の部分をレポート ウィンドウの上書きではなく、行フィルターとしてのみ評価します。 セグメント内のすべての条件は、フィードの配信ウィンドウ内で尊重されます。

## セグメントの選定とルックバック期間

個人またはセッションコンテナを使用するセグメントの場合、選定は、配信ウィンドウだけでなく、**ルックバック日付範囲**&#x200B;の設定によって決まります。 ユーザーがルックバック日付範囲内に該当する場合、そのユーザーの配信ウィンドウ内のすべてのイベントが含まれます。 コンテナ設定によってスコープが決まります。

- **イベントコンテナ**：配信ウィンドウ内のセグメント条件に一致するイベントのみが含まれます。
- **セッションコンテナ**：配信ウィンドウ内の適格セッション内のすべてのイベントが含まれ、セッションの選定がルックバック日付範囲にわたって評価されます。
- **人物コンテナ**：配信ウィンドウ内のすべてのイベントは、ルックバック日付範囲内に適格な人物に含まれます。

ルックバック日付範囲と、それがセグメントの選定にどのように影響するかについては、[ データフィードの作成](/help/components/exports/cja-data-feeds/create-feed.md)を参照してください。

## Analysis Workspaceとの比較

| 動作 | Analysis Workspace | データフィード |
|---|---|---|
| 日付範囲セグメントがレポートウィンドウを上書きする | はい | いいえ |
| レポートウィンドウ内の行をセグメントフィルター | はい | はい |
| データビューセグメントが適用されます | はい | はい |
| 配信に直接適用される追加セグメント | いいえ | はい |
